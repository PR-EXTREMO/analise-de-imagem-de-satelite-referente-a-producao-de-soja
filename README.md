# Análise de Imagens de Satélite Aplicada à Produção de Soja utilizando LabelImage

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-yellow)
![Projeto acadêmico](https://img.shields.io/badge/projeto-acad%C3%AAmico-blue)

Projeto acadêmico da disciplina de **Laboratório de Programação**, voltado à análise de áreas produtoras de soja por meio de imagens de satélite e técnicas de geoprocessamento e processamento de dados.

## Sobre o projeto

O projeto busca utilizar imagens do satélite **Sentinel-2** e para acompanhar áreas agrícolas e identificar diferenças no vigor da vegetação ao longo da safra.

A analise sera realizada utilizando o programa **LabelImage**, que permite a classificação de imagens e a criação de mapas temáticos, além de possibilitar a geração de gráficos e indicadores para auxiliar na interpretação dos resultados.

## Objetivo geral

Desenvolver um aplicativo que baixe as imagens do Sentinel-2.

## Objetivos específicos

- Selecionar uma propriedade ou região de interesse;
- Obter imagens gratuitas do Sentinel-2;
- Processar as imagens utilizando o Google Earth Engine;
- Classificar as imagens utilizando o LabelImage;    


## Funcionalidades planejadas

| Tecnologia | Utilização |
|---|---|
| Google Earth Engine | Consulta e processamento de imagens de satélite |
| Sentinel-2 | Fonte gratuita das imagens multiespectrais |
| LabelImage | Classificação de imagens e criação de mapas temáticos |    
| Node.js | Desenvolvimento do aplicativo para baixar imagens |
